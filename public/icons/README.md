# PWA Icons — Shop Albie

Place the following icon files in this folder:

| File                  | Size      | Usage                                 |
|-----------------------|-----------|---------------------------------------|
| `icon-192.png`        | 192×192   | Android home screen / PWA             |
| `icon-512.png`        | 512×512   | Splash screen / large displays        |
| `apple-touch-icon.png`| 180×180   | iOS "Add to Home Screen"              |
| `favicon.ico`         | 32×32     | Browser tab favicon                   |
| `screenshot-mobile.png`| 390×844  | PWA install dialog screenshot        |

## Design guideline

The icon should show the **"A" monogram** or styled **"Albie"** wordmark on a black `#0a0a0a` or cream `#fdfdfd` background.

All icons must be added manually — create or commission them using the brand direction agreed for Shop Albie.

## Quick icon generation (free)
1. Design the mark in Figma, Canva, or Adobe Express
2. Export as 512×512 PNG
3. Use https://www.pwabuilder.com/imageGenerator to generate all sizes at once
